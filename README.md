# Pinteresting

Šolski projekt izdelave lastnega obrazca po vzoru Pinteresta.

## Uporabljene tehnologije

- HTML
- CSS
- JavaScript
- SweetAlert2

## Funkcionalnosti

- Prijava uporabnika
- Registracija uporabnika
- Povezava med obrazcema
- Prijava prek Googla, Facebooka in Appla
- Pojavna sporočila ob oddaji obrazcev

## Zagon projekta

1. Prenesi repozitorij.
2. Odpri datoteko `index.html` v spletnem brskalniku.
3. Za registracijo odpri `registracija.html`.

## Struktura projekta

- `index.html` – obrazec za prijavo
- `registracija.html` – obrazec za registracijo
- `style.css` – oblikovanje strani
- `script.js` – JavaScript in pojavna sporočila
- `README.md` – opis projekta

## Opomba

Prijava in registracija sta namenjeni prikazu delovanja obrazcev. Podatki se ne shranjujejo v podatkovno bazo.
